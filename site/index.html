macOS · local only · beta version 0.1.2

Separate profiles. Clear identities.

Run multiple accounts of a compatible Electron or Chromium app at the same time, with permanent numbers and independent profile directories.

No telemetry · no network access

Isolated

Each instance receives its own Chromium user-data directory. Full-compatible apps also receive a numbered bundle identity and Dock icon.

Reversible

The original application is never modified. Confirmed removal is exact-path bounded and moves owned items to the Trash where macOS permits.

Honest

Keychain, privacy permissions, URL schemes, Lite-mode sharing, ad-hoc signing, and unsupported apps are disclosed instead of hidden.

Current fix

Windows return from disconnected displays

Version 0.1.2 detects the recognized Electron window-state shape before launch. When no draggable part of the saved title bar exists on any active display, the generated launcher preserves the original state and centres the window on the main screen.

Existing instances: install 0.1.2, then choose Rebuild from Source App once so the generated launcher receives the new repair logic. The profile, sign-in, name, and permanent number are preserved.

Distribution

Builds say what they are

Local builds are ad-hoc signed and are suitable for testing on the machine that built them. A broadly distributed release must be Developer ID signed, notarized by Apple, stapled, and accompanied by a checksum. The project never presents an ad-hoc artifact as notarized.
