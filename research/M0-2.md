# M0-2 — Instance data stays inside its own directory

**Outcome:** NEEDS HUMAN CONFIRMATION
**Run:** 2026-07-25T16:31:38Z

## Pass condition

An instanced process performs no writes to the application's default Application Support directory.

## Result

No instanced process held a file open in the default directory, but the directory's fingerprint changed. This is expected if a non-instanced copy of the app was also running.

## Findings

- `--user-data-dir` redirects auth tokens, cookies, localStorage, IndexedDB, cache and the singleton lock. It does not redirect the Keychain, and nothing in this product tries to.

## What a human must confirm

1. Quit every copy of Claude, including any started outside this harness.
2. Re-run `mal m0 --only 2`.
3. For a byte-level trace, run `sudo fs_usage -w -f filesystem <pid>` alongside the instance. fs_usage requires root, which this product never takes on its own.
