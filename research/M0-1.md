# M0-1 — Two instances with separate --user-data-dir

**Outcome:** NEEDS HUMAN CONFIRMATION
**Run:** 2026-07-25T16:31:38Z

## Pass condition

Both run simultaneously; each can be signed in to a different account; both stay signed in after quit and relaunch.

## Result

Two processes started from one bundle and each populated its own profile directory. Whether two *accounts* stay signed in is a human check.

## Findings

- 2 new processes: 53292, 53396.
- Chromium's SingletonLock is per --user-data-dir, so a distinct directory removes the single-instance block. Both profiles were written to, which is the observable form of that.

## What a human must confirm

1. Run `mal m0 --only 1 --keep` so the two windows stay open.
2. Sign in to account #1 in the first window and account #2 in the second.
3. Quit both. Relaunch with the same two `--user-data-dir` values.
4. Confirm each window comes back signed in to its own account. That is the actual pass condition.
